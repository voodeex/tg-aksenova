# Аксёнова Татьяна Геннадьевна — Цифровое портфолио

Персональное интерактивное 3D-портфолио преподавателя высшей квалификационной категории, кандидата педагогических наук, преподавателя Колледжа информатики и программирования Финансового университета при Правительстве Российской Федерации.

**Онлайн-версия (GitHub Pages):** https://voodeex.github.io/tg-aksenova/

## Стек

- **Next.js 16** + **React 19** + **TypeScript** + **Tailwind CSS v4**
- **Three.js** + **React Three Fiber** + **@react-three/drei** + кастомные GLSL-шейдеры
- **GSAP** + **ScrollTrigger** + **Lenis**

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build        # обычная сборка Next.js
npm run build:pages  # статический экспорт для GitHub Pages (./out)
```
